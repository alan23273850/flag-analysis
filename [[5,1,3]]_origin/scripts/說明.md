# [[5,1,3]]_origin/scripts 腳本說明

本目錄的五支 `_513` 腳本都圍繞同一個 **[[5,1,3]] flag syndrome 協定**，但方法不同：有的做**隨機模擬**，有的做**確定性窮舉**，有的做**精確加權計數**。

```
n_2q_gate_fault_dfs_513  →  確定性窮舉（驗證 / 找反例）
sim_513                  →  核心：隨機噪聲模擬一次協定
monte_carlo_table_513    →  大量跑 sim_513，估計失敗率
wmc_513                  →  核心：精確加權 model counting
wmc_table_513            →  多個 p 點跑 wmc_513，輸出表格
```

---

## 1. `sim_513.py` — 核心隨機模擬器

**一次**跑完 [[5,1,3]] origin flag syndrome 協定，並注入物理噪聲：

- 讀取 QASM（flag circuit + raw syndrome circuit）
- 依序跑 4 個 stabilizer round（XZZXI, IXZZX, XIXZZ, ZXIXZ）
- 在每個 CX/CZ 後以機率 `p` 注入 2-qubit Pauli fault
- 也模擬 idle error（`gamma`）、測量 error（`beta`）、ancilla prep error
- 若某 round 的 syndrome `(s,f) ≠ (0,0)`，進入第二 subround（raw syndrome），產生 6-bit LUT 輸出
- 回傳 LUT 紀錄、data qubit 的 X/Z 錯誤、以及注入的 fault 事件

單獨執行時會再呼叫 `verify_decoder_commute`，檢查 decoder 公式是否與 log+stab 對易。

---

## 2. `monte_carlo_table_513.py` — Monte Carlo 失敗率表格

**批次驅動** `sim_513.py`，用統計方式估計：

```
ratio_fail = decoder_fail / total_runs
```

- 對多個物理錯誤率 `p`（預設約 1e-5 ~ 1e-4）各跑到累積 **1600 次 decoder fail**
- 每次有 LUT 輸出時，用 `decoder/path_*.txt` 做 commute 檢查
- 支援多 process 平行（預設 128）
- 輸出到 `mc_results/`（CSV + TXT）

**用途**：用 Monte Carlo 估計在不同 `p` 下 decoder 失敗的機率。

---

## 3. `n_2q_gate_fault_dfs_513.py` — 確定性 DFS 窮舉

**不抽樣**，用 depth-first search **窮舉所有可能的 2-qubit fault 軌跡**（最多 N 個 fault，預設 N=1）：

- 4 個 stabilizer round 各走各自的 QASM
- 每個 CX/CZ 後可選：無 fault，或 15 種非 identity Pauli（control/target 的 X/Z flip）
- 若 `(s,f) ≠ (0,0)` 就進 raw round（r_4），同樣枚舉 fault
- 每條 leaf 做 decoder commute 檢查，統計 PASS/FAIL
- 可 `--stop-on-first-fail` 找第一個反例，並輸出 SMT fault assert（供 boolean learning 用）

**用途**：形式化驗證 / 除錯——確認在有限 fault 數下 decoder 是否都正確，或找出失敗軌跡。

---

## 4. `wmc_513.py` — 加權 Model Counting（精確計算）

Monte Carlo 的**精確替代**：不算 `ratio_fail = decoder_fail / total_runs`，而是用 **projected weighted model counting (PWMC)** 做加權求和（`gpmc -mode=3`）：

- 對每個 first triggering stabilizer `t ∈ {0,1,2,3}`：
  1. 用 Z3 符號模擬協定（fault 變成 Boolean indicator）
  2. 建 failure 公式：`path_condition(t) AND NOT all_commute(data XOR decoder)`
  3. Tseitin 轉 CNF，輸出 MCC2021 加權 DIMACS
  4. 呼叫 `gpmc` 算加權 count
- 四條 path 的機率加總 = `ratio_fail`
- 可設 `--max-faults 2` 做 cardinality 截斷（distance-3 通常夠用）

**用途**：在給定 `p`、`gamma`、`beta` 下精確算 decoder 失敗機率（在截斷假設內）。

---

## 5. `wmc_table_513.py` — WMC 表格驅動

介面與輸出格式對齊 `monte_carlo_table_513.py`，但底層改呼叫 `wmc_513`：

- 對多個 `p` 點（預設 1e-5, 2e-5, 5e-5, 1e-4）各算一次 WMC
- CSV 欄位：`p, beta, gamma, max_faults, ratio_fail, path_t0..t3_fail, total_vars, total_clauses, elapsed_sec`
- 輸出到 `wmc_results/`

**用途**：產生 WMC 版失敗率表格，和 MC 結果對照或收斂驗證。

---

## 簡表

| 腳本 | 方法 | 主要輸出 |
|------|------|----------|
| `sim_513.py` | 隨機模擬 1 次 | LUT + decoder PASS/FAIL |
| `monte_carlo_table_513.py` | 大量 MC 模擬 | `mc_results/` 失敗率表 |
| `n_2q_gate_fault_dfs_513.py` | DFS 窮舉 fault | PASS/FAIL 統計、反例 SMT |
| `wmc_513.py` | 精確 WMC（單一 p） | `ratio_fail` + 各 path 機率 |
| `wmc_table_513.py` | 多 p 點 WMC | `wmc_results/` 失敗率表 |

---

## 建議使用方式

- **驗證 decoder 正確性**：`n_2q_gate_fault_dfs_513.py`
- **快速估計失敗率**：`monte_carlo_table_513.py`
- **精確失敗率（對照 MC）**：`wmc_table_513.py`
